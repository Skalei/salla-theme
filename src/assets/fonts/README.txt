Kohinoor Arabic is a licensed (paid) typeface and cannot be bundled with the theme scaffold.

Place the licensed .woff2 files here with these exact names (referenced from styles/02-base.css):
  KohinoorArabic-Regular.woff2
  KohinoorArabic-Medium.woff2
  KohinoorArabic-Semibold.woff2
  KohinoorArabic-Bold.woff2

Until the files are added, the theme falls back gracefully to Montserrat (Latin, via Google Fonts)
and the system Arabic font stack.
